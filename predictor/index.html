Explore stored LightGBM predictions from the final holdout, compare them with actual sales, and test how an absolute-error tolerance changes the interpretation of a prediction.

What this page does: it inspects precomputed holdout predictions. It does not run a new LightGBM forecast from user-entered features. The trained model artifact and an inference service are not part of this static GitHub Pages deployment.

ERROR TOLERANCE CONTROL

How large a miss is acceptable?

Move the slider to apply an illustrative absolute-error tolerance in sales units to the currently selected sampled row. This classifies the row; it does not alter the model prediction.

The tolerance is an interactive decision threshold for demonstration, not a metric or business rule selected during model training.
